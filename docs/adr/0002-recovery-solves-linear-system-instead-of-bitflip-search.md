# Recovery solves a linear system over the candidate columns instead of brute-force bit-flipping

For a broken packet `r` with `K` candidate corrupted columns (from ACR), every other, trusted packet `p_j` in the generation gives one cross-tag equation `Σ mul(p_j[c], x_c) = T_j` (known columns of `r` moved to the constant `T_j`) — linear in the `K` unknown bytes `x_c`, because field multiplication is linear in each factor. Stacking one such row per trusted packet gives a `(gen_size-1) × K` matrix equation `A·x = b`. We decided to solve this directly via Gaussian elimination (reusing the pivot/elimination primitives already in `rref.py`: `_find_pivot`, `_subtract_pivot_from_matrix`, `get_mul_to_target`, `invert_pivot_rows`, run on the `K`-column submatrix restricted to candidate columns with `b` appended) rather than brute-force bit-flipping candidate byte values and re-checking orthogonality (the previous approach in `recover_packet`/`recover_packet_bitflip`).

We considered keeping bit-flip search as the primary mechanism, but rejected it: brute force is probabilistic (per [ADR-0001](0001-recovery-acceptance-oracle.md), any single equation always has a solution, so "it passed" isn't proof), whereas solving the linear system is exact — it either produces the unique correct value or proves the candidate column set is inconsistent. It also isn't more code: it's the same Gaussian-elimination machinery `arc()` already runs for localization, just applied to a small per-packet system instead of the whole generation.

This requires at least `K` of the `gen_size-1` other packets to give independent rows at the candidate columns. Any surplus rows beyond `K` aren't needed for the solve but double as a free consistency check (a mismatch flags a wrong candidate column set or a second corrupted "trusted" packet); the self-tag equation is a further, structurally independent check since squaring is Frobenius-linear rather than scalar-linear.

Resolved by [ADR-0003](0003-defer-recovery-until-enough-trusted-packets.md): recovery waits for enough trusted packets to arrive before solving, falling back to bit-flip search only if the system is still underdetermined.
