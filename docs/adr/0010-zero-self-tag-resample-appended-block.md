# A zero self-tag is a degenerate object to reject-and-resample on the appended block, not a payload to rewrite or a whole generation to regenerate

The orthogonal-tag scheme fails whenever a packet's **self-tag** comes out `0`. In characteristic 2 the self-tag of a packet is exactly the XOR-checksum of its bytes (`<p,p> = (XOR of bytes)^2`, and the tag is `sqrt(<p,p>)`), so a zero self-tag means the packet already XORs to zero. It is not merely useless: because later packets build their cross-tags against an earlier packet's self-tag via `generate_tag_cross(t1=that self-tag, d)`, a `t1 == 0` makes the solve `t1 * t2 = d` degenerate and the code falls back to a *random* tag (`orthogonal_tag_creator.py`), so orthogonality can no longer be forced and the whole generation fails `check_orth`. This ADR fixes how we respond to a zero self-tag.

**Current behavior (the baseline this ADR replaces as the default).** `generate_symbols_until_nonzero` (`binary_ext_fields/generate_symbols.py`) regenerates the **entire generation** — new random data for every packet — and re-tags, looping until all self-tags are nonzero *and* `check_orth` passes. It works but pays an exponential cost in generation size (see below) and, more importantly, assumes the payload is ours to throw away.

**Decision: treat a zero self-tag as a degenerate member to reject and resample, and resample the smallest free thing — never the payload.** Concretely, in order of preference by context:
1. **Recoded packets** carry random coefficients already — resample the coefficient row of the offending packet. Free; no extra bytes, no payload touched.
2. **Source packets with a mutable payload** — resample only that one packet's data (**solution 2**), not the whole generation.
3. **Source packets with a FIXED payload** — append one per-packet **salt byte** to the tagged region's input and resample the salt *vector* until every self-tag is nonzero. Payload is transmitted verbatim; overhead is one symbol per packet. This is effectively a guarantee in GF(2⁸) (Monte-Carlo `0/5000` unsolvable) but **not** a hard guarantee in small fields (`4%` unsolvable in GF(2²)) — see the cost/caveat note below and the deferred guaranteed construction.

**Why this is the right shape — the linear-algebra reason.** Stacking the tag columns into a `g x g` matrix `T`, full orthogonality is exactly `T . T^T = G`, where `G[i][j] = <payload_i, payload_j>` is the payload Gram matrix; the greedy generator is a Cholesky/LDL^T factorization and a **zero self-tag is a zero pivot**. Over a field of characteristic 2, a nondegenerate symmetric form admits a nonzero-diagonal factorization iff it is **not alternating** (symmetric with zero diagonal) — Conrad, *Bilinear Forms*, Ex. 5.4. Reordering the packets is a congruence `P^T G P`, which **preserves** the alternating property, so reordering (the `generate_all_tags_with_swap` idea) provably cannot fix a fully-alternating Gram matrix, and for `g = 1` nothing in the tag space can help at all. The general escape is therefore an extra degree of freedom, which Lempel–Seroussi (SIAM J. Comput. 1980) show is minimal — the "rank+1" column. The salt byte is that column; resampling coefficients/data is the same move where those bytes are already free.

**Why not the payload.** Rewriting payload to dodge degeneracy has no precedent in the network-coding integrity literature and breaks the "data is sacred" contract. Every crypto scheme in the family appends a unit-vector coefficient block precisely so that non-degeneracy lives on appended structure, not the message (Charles–Jain–Lauter §3.1; Agrawal–Boneh). Agrawal–Boneh's homomorphic MAC explicitly names an all-zero coefficient block a **"trivial forgery"** — a degenerate object excluded by definition — which is the exact analog of the zero self-tag. Kehdi–Li "Null Keys" (INFOCOM'09), the ancestor of the orthogonal-tag idea, handles its degenerate case by **resampling null-space basis vectors, not payload**. Zhang et al. "Padding for Orthogonality" / MacSig (INFOCOM'11) is the direct precedent for the salt byte: the source **appends one extra symbol solved so the orthogonality relation holds, payload untouched**. See `docs/research/network-coding-mac-degenerate-packets.md`.

**Cost — the trade this ADR turns on.** With `q = 2^m` and generation size `g`, the per-packet probability of a zero self-tag is `A = 1/q` (exact for the first packet; a documented small-field approximation otherwise — see `docs/zero_tag_probability.md`). Regenerating the whole generation costs `g * (q/(q-1))^g` packet-generations — **exponential in `g`**. Resampling a single (mutable) packet costs `g * q/(q-1)` — **linear in `g`**. Both are Monte-Carlo-confirmed in `simulation/zero_tag_probability.py` (e.g. GF(2⁴) `g=8`: ≈13.3 vs ≈8.5 packet-generations).

**Salt caveat.** One salt byte is *not* a hard guarantee: packet `i`'s self-tag depends on the salt as `salt_i · (1 + Σ_{k<i} salt_k / t_k)`, so when that multiplier is zero no salt value moves it off zero. One extra column guarantees a nonzero-diagonal factorization *exists* (Lempel–Seroussi rank+1), but the greedy generator + random salt sampling need not *find* it. Resample the whole salt *vector* (single-position resampling can loop forever); MC unsolvable rates: `0/5000` in GF(2⁸), `0.02%` in GF(2⁴), `4.0%` in GF(2²). In GF(2⁸) it is a guarantee for practical purposes; small fields need the fallback below. Every solved generation keeps the payload byte-for-byte intact and passes full `check_orth`.

**Consequences.**
- The scheme gains a fixed-data mode it did not have: a source can tag an application payload it is not allowed to alter, at one salt symbol per packet of overhead (a guarantee in GF(2⁸); small fields keep a fallback).
- `generate_symbols_until_nonzero` remains valid and unchanged. Two additive siblings implement this decision without touching it (so nothing currently working breaks): `generate_symbols_single_resample` (mutable data, resamples only offending packets) and `generate_symbols_salt(field, payloads, gen_size)` (fixed payload + salt vector, returns `(gen, ok)` with `ok=False` on the small-field give-up). Both in `binary_ext_fields/generate_symbols.py`.
- The salt byte enters the Gram matrix like any payload symbol, so cross-orthogonality is enforced normally; no verifier change is required.

**Deferred, explicitly:**
1. **2x2 hyperbolic pairing for even-clustered degeneracies.** The char-2 analog of Bunch–Kaufman 2x2 pivoting is the symplectic decomposition into hyperbolic `[[0,1],[1,0]]` blocks (Conrad Thm 5.4); this is the same structure as the thesis's "combined recovery / XOR two packets." It can resolve an *even* cluster of degenerate packets without a salt byte, but an odd leftover still needs one free coordinate. Not needed given the salt byte already solves the general case.
2. **Reorder-first, salt-fallback hybrid** — try symmetric pivoting (`generate_all_tags_with_swap`) and only spend a salt byte when the residual Gram submatrix is alternating. Saves the overhead byte in the common case; deferred as an optimization.
3. **Exact position-dependent probability** capturing the small-field correlation bias (Q8/(B)); left as future work in the probability doc.
