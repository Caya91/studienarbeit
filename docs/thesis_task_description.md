## Hybrid Packet Recovery and HMAC Verification in Network Coding Systems

Network coding, particularly Random Linear Network Coding (RLNC), optimizes communica
tion over lossy links, especially in wireless networks. While CRC checksums help detect errors
from noise or attacks, they prevent recoding of partially broken packets, limiting RLNC per
formance. Homomorphic Message Authentication Codes (HMACs) offer a better alternative,
using tags and keys to verify packet integrity, allowing partial packet to participate in recoding
and reducing computational load.
This study aims to analyze the effectiveness of tags in detecting partially broken packets,
whether intentional or unintentional. The student in this thesis is expected to develop aframe
work for generating appropriate tags to detect erroneous RLNC-coded packets and evaluate
optimization gains compared to CRC checksums across various scenarios. The study will also
assess throughput, communicationoverhead, andtheaccuracyofpacketrecoverytechniques
like Packetized rateless algebraic consistency (PRAC) when using tags versus CRCs.
Asarequirement,thestudentmustdocumenttheoutcomeoftheprojectworkinascientific
report.
Focus of work
• Conducting a literature review on packet pollution in network coding, recovery
strategies, and HMAC-based verification.
• Implementing combined packet recovery and HMAC verification mechanisms.
• Evaluating detection speed and recovery effectiveness compared to conventional ARQ.
• Measuring performance metrics such as latency, throughput, and computational
overhead.
• Analyzing trade-offs between additional overhead and reliability gains.
• Preparing an intermediate presentation and a final report for the thesis.
